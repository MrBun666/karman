# Карман 2.0 — Android-приложение для учёта денег

## Что умеет

- **Сам записывает траты.** Пришёл пуш от Kaspi, Halyk или другого банка — расход сразу записан, категория выбрана, а «Карман» показывает уведомление «Записал: −3 500 ₸ · MAGNUM».
- **Наличные голосом.** Скажи «такси две тысячи наличными» — запись готова.
- **Напоминания.** О платежах из календаря (накануне и в день платежа), вечерний итог дня, итоги недели по воскресеньям.
- **Виджет на главном экране.** Показывает, сколько можно тратить сегодня, и даёт кнопки «+ Расход» и 🎤.
- **«Поделиться» → Карман.** Выписка Kaspi в PDF, фото чека или текст уведомления.
- Всё из прошлых версий: календарь «на постоянку», отчёты за день, неделю и месяц, цели, кредиты, аналитика, ИИ-чат, чеки по фото.
- **Данные остаются на телефоне.** Сервер не нужен.

## Установка (один раз, примерно 20 минут)

APK собирается бесплатно на GitHub: ты загружаешь код, через 5–7 минут готов файл для установки.

### 1. Репозиторий на GitHub
1. Зарегистрируйся на github.com.
2. Нажми **New repository**, назови его `karman`, выбери **Public** и нажми **Create repository**.
3. Нажми **uploading an existing file** и перетащи **всё содержимое** папки `karman` из архива:
   - папки `www`, `android`, `.github`;
   - файлы `README.md` и `.gitignore`.

   Папка `.github` скрытая — включи показ скрытых файлов, иначе сборка не запустится.
4. Нажми **Commit changes**.

> Загружать много файлов с телефона неудобно. Если под рукой нет компьютера, создай пустой репозиторий и скажи мне его название — я загружу файлы сам.

### 2. Ключ подписи (секреты)
Ключ нужен, чтобы новые версии ставились поверх старой и данные сохранялись.

1. В репозитории открой **Settings → Secrets and variables → Actions → New repository secret**.
2. Создай два секрета из файла `СЕКРЕТЫ-ДЛЯ-GITHUB.txt`: `KEYSTORE_PASSWORD` и `KEYSTORE_BASE64`.
3. Сам файл с секретами **не загружай в репозиторий**. Сохрани его отдельно, например в Telegram «Избранное».

### 3. Сборка
1. Открой вкладку **Actions → Сборка APK → Run workflow**. Сборка также запускается сама при каждой загрузке файлов.
2. Через 5–7 минут появится зелёная галочка.
3. Если стоит красный крестик, открой сборку, скопируй текст ошибки и пришли мне.

### 4. Установка на телефон
1. На телефоне открой `https://github.com/ТВОЙ_ЛОГИН/karman/releases`.
2. Скачай файл `karman-….apk` и открой его.
3. Android спросит разрешение устанавливать приложения из браузера. Разреши и нажми **Установить**.

### 5. Включить автоматический учёт
1. Открой «Карман», пройди первый экран и разреши уведомления.
2. Приложение предложит **доступ к уведомлениям**: найди в списке «Карман» и включи переключатель.
3. ⚠️ **На Android 13 и новее** переключатель может быть серым с надписью «Ограниченная настройка». Так Android защищает приложения, установленные не из Play Маркета. Что сделать:
   1. Открой **Настройки телефона → Приложения → Карман**.
   2. Нажми **⋮** в правом верхнем углу → **Разрешить ограниченные настройки** и подтверди.
   3. Вернись в доступ к уведомлениям и включи «Карман».
4. **Xiaomi, Redmi, POCO, Samsung, Huawei:** в настройках приложения «Карман» поставь **Батарея → Без ограничений**. Иначе система может «усыпить» чтение уведомлений.
5. В **Настройки → Автоматический учёт** отметь, из каких приложений записывать траты:
   - банки отмечены по умолчанию;
   - Onay, Yandex Go и Glovo лучше не отмечать: их оплата и так приходит уведомлением от банка, иначе трата запишется дважды.

### 6. Виджет
Долгое нажатие на главный экран → **Виджеты** → **Карман** → перетащи на экран.

### 7. ИИ (по желанию)
Чат, чеки по фото и нестандартные выписки работают через Claude API:
1. Зайди на console.anthropic.com → **API Keys** и создай ключ.
2. Пополни баланс и поставь месячный лимит.
3. В приложении: **Ещё → Настройки → API-ключ**.

## Обновления

1. Поменяй файлы и загрузи их в репозиторий.
2. По желанию увеличь `APP_VERSION` в `www/js/version.js` и напиши в `APP_NOTES`, что нового.
3. GitHub сам соберёт новый APK и выпустит релиз.
4. Приложение при открытии покажет плашку «Новая версия — Скачать». Открой скачанный файл и нажми **Обновить**. Данные сохранятся.

> Новая версия ставится поверх старой, только если она подписана **тем же ключом**. Поэтому не теряй файл с секретами.

## Перенос данных из веб-версии
Если раньше пользовался «Карманом» в браузере, перенеси данные так:
1. В веб-версии: **Ещё → Резервная копия**.
2. В приложении: **Ещё → Импорт → Восстановить**.

## Резервные копии
Данные хранятся только на телефоне. Раз в 1–2 недели делай **Ещё → Резервная копия** и сохраняй файл в Telegram или на Google Диск. Приложение само напоминает об этом.

## Как это устроено

```
www/                    веб-часть (интерфейс, расчёты, ИИ) — общая для APK и браузера
  js/version.js         ← НАЗВАНИЕ, ВЕРСИЯ и список изменений
  js/native.js          связь с Android
android/                Android-оболочка (Java)
  MainActivity          окно с интерфейсом, файлы, камера, голос, «Поделиться»
  MoneyListenerService  чтение денежных уведомлений банков
  Reminders/…Receiver   напоминания по расписанию (переживают перезагрузку)
  BalanceWidget         виджет «можно тратить сегодня»
.github/workflows/      автосборка APK и выпуск релиза
```

**Как распознаются уведомления.** В расчёт идут только уведомления с суммой в ₸, KZT или «тг» и словом операции: покупка, оплата, перевод, пополнение, снятие и т.д. Рекламные (со словами «скидка», «акция», «одобрен» и т.п.) отбрасываются. Если одна покупка пришла уведомлениями из двух разных приложений в течение 15 минут, она записывается один раз. Выписка Kaspi, загруженная позже, тоже не создаёт дублей.

**Если уведомление банка разобралось неверно,** перешли мне его текст (сумму и имена можно изменить) — подправлю правила.
